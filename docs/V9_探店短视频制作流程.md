# V9 抖音竖屏探店视频制作流程

> 案例：观感专业美发沙龙（安吉）　成片：观感沙龙_V9烫染探店.mp4
> 目标：彻底解决 V8b「照片轮播像幻灯片 + 音乐是假音乐」两个致命问题。

---

## 一、先诊断，别急着做

V8b 被用户判定为「幻灯片」。诊断结论：

| 现象 | 真实原因 |
|---|---|
| 成片像幻灯片 | 4 张照片是**同一场景的连续瞬间**（同机位、同构图），轮播必然雷同 |
| 素材同质 | 视频是微信压缩版（720×406 / 708Kbps / `Lavf60.16.100`），只有 2.9 秒 |
| 「假音乐」 | `citypop_76_暖夜` 元数据是 `FluidR3_GM`，MIDI 音源合成 |

**关键动作**：先把问题归因到「素材物理上限」，再决定能做到什么程度。
不要用后期硬怼一个素材本身就不支持的体裁。

---

## 二、六层改造（按优先级）

### 1. 紧凑特写替代广角（同构图是幻灯片的元凶）

横构图 3:2 原图硬裁 9:16 必然丢主体。必须**先用主体框定位再裁**：

```python
# 主体框用原图坐标，窗口自动包住主体并保持目标比例
wx = int(bw * pad); wy = int(bh * pad)
if wx / wy < tr: wx = int(wy * tr)
else: wy = int(wx / tr)
```

放大倍数控制在 **2.4~4×**（源 2133px，等效 1080p 级锐利）。详见 `tools/make_assets_v9.py`。

### 2. 双层同动（画面永远有运动）

- 底层：紧凑特写填满 1080×1920，zoompan 等比推进
- 上层：真实视频条 1080×608 叠压（保持 16:9 原比例，只放大 1.5×，不糊不畸变）

**坑**：`overlay` 输出尺寸跟随第一个输入。绝不能用 `pad` 拼两个不同尺寸的层（会出黑边），
必须「底层填满 + 上层叠压」。

### 3. zoompan 等比运镜

```bash
zoompan=z='min(max(1.0+0.12*on/38,1.0),1.12)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=48:s=1080x1920:fps=30
```

三个必踩的坑：
1. `zoom` 变量**每次输入帧重置** → 必须用 `on`（输出帧计数）做线性插值
2. zoompan 会把裁切区**强制拉伸**到 s 尺寸 → 要等比运镜必须先预放大成大画布（BIG_*）
3. 静态图只有 1 帧输入 → `d` 必须等于目标帧数（不是 `d=1`）

### 4. DP 求解卡点切镜

不要人工拍切点。用动态规划在音乐重音上求最优切分序列，详见 `tools/dp_beats.py`。

实测结果：14 镜，时长 1.24~1.85s，全部落在重音上。

### 5. 转场闪白

每个切点开头 0.05s 柔白闪（峰值 55%）。**注意**：直接用纯白 100% 会造成整格过曝，
必须用 `colorchannelmixer=aa=0.55` 压到 55%。

### 6. 文字层（三层）

| 层 | 内容 |
|---|---|
| 开场花字 | 店名 + 定位，金边立体 + zoompan 弹入回弹 |
| 逐镜字幕 | 每镜一条，跟随镜头起落，底条 alpha 必须 ≥ 218 才够清晰 |
| 结尾 CTA | 团购引导 + 金色按钮 |

金边算法：**一次性 `stroke_width` 描边**，不要逐层缩小描边（会形成同心圆环填糊字腔）。

## 三、音乐选型：别只看曲名

同样 CC0、真人录音的曲子，切点质量差距是数量级的。用**低频瞬态总量**量化：

| 曲名 | kick 瞬态总量 | 高能段 | 结论 |
|---|---|---|---|
| Miniature Saloon（名字最对口） | **84.9** | 仅 8-10s | 刷鼓无底鼓，卡点飘 |
| Wednesday Night [Funk Fusion] | **194,116** | 44-80s / 116-156s | 切分 funk，卡点干脆 ✅ |

差 **2285 倍**。选曲流程：下载 → 算 kick 瞬态 → 定位高能段 → DP 求解切点。

## 四、渲染流程（分步，防 OOM）

```
dp_beats.py  → bounds.json
make_assets_v9.py → A_*.jpg / B_*.jpg → BIG_*.jpg
make_text_v9.py → open_flower.png / sub_*.png / cta.png
build_v9.py → shot_00..13.mp4
concat → v9_concat.mp4
compose_v9.py → V9_final.mp4
```

**Step2 字幕必须逐条叠加**：一次性串 13 层 overlay 会 OOM（进程被杀但 returncode 可能仍是 0，
输出文件 0 字节，极难排查）。

## 五、响度链路

| 环节 | 处理 |
|---|---|
| 音乐源 | `loudnorm=I=-16:TP=-1.5:LRA=9` → 实测 -16.03 LUFS / TP -3.67 |
| 混音 | `volume=-1.5dB,alimiter=limit=0.841` |
| 成片实测 | **-16.12 LUFS / TP -3.78 dBTP / LRA 2.20** ✅ |

**坑**：不要在 loudnorm 之后再加 `volume=1.0dB`，那会把 TP 顶到 0 dBTP。

## 六、三道尺验收

```bash
# 黑场
ffmpeg -i out.mp4 -vf "blackdetect=d=0.10:pix_th=0.10" -an -f null -
# 冻结
ffmpeg -i out.mp4 -vf "freezedetect=n=0.003:d=0.6" -an -f null -
# 静音
ffmpeg -i out.mp4 -af "silencedetect=n=-45dB:d=0.6" -vn -f null -
# 响度
ffmpeg -i out.mp4 -af loudnorm=I=-16:TP=-1.5:print_format=json -vn -f null -
```

抖音目标：**-14~-16 LUFS，TP ≤ -1.5 dBTP，无黑场/冻结/静音**。
