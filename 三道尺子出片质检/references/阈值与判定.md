# 阈值与判定

所有锐度阈值都在**尺度归一 + 噪声扣除**口径下：

```
等效锐度 = (lap × 实测宽/640) − 20σ² × 实测宽/640
```

- 归一指数 1.0 是实测标定的（1680 原生 996 ↔ 缩到 640 是 2599，比值 2.61 = 1680/640）
- 噪声项 20σ² 来自拉普拉斯核 `[[0,1,0],[1,-4,1],[0,1,0]]` 的系数平方和；σ 用响应幅值 25 分位估

## 画质口径（BRISQUE）

代码在 `scripts/aesthetic.py` 的 `BRISQUE_LEVELS`，折扣系数乘在清晰度维度上（`s += 22*q*_k`，`_k = min(画质系数, 噪点系数)`）：

| BRISQUE | 折扣 | 判 |
|---|---|---|
| <45 | 1.00 | 干净/可用，不打折 |
| 45-55 | 0.86 | 画质偏软 |
| 55-60 | 0.62 | 压缩损伤可见 |
| 60-70 | 0.40 | 压缩损伤明显 |
| >70 | 0.22 | 画质严重劣化 |

**只在 `is_final=False`（素材）时生效**。成片必须传 `is_final=True`，否则花字会被当成结构异常，好片被杀到 0.22 折。

注意：`is_final=True` 时 `qual_penalty` 字段仍会照常算出并记录（如 0.22），但**不参与打分** —— 它是诊断值，不是扣分依据。看到成片 `qual_penalty=0.22` 是正常的，别去"修"它。

素材闸门 `GATE`：`warn_brisque=52`（超了只警告）、`max_brisque=75`（留作极端情况参考，不硬拒）。

## 跨尺度能量比（只判噪点）

| 比值 | 系数 | 判 |
|---|---|---|
| ≥1.05 | 1.00 | 正常 |
| 0.75-1.05 | 0.60 | 噪点偏多 |
| 0.45-0.75 | 0.35 | 噪点明显 |
| <0.45 | 0.20 | 噪点盖过细节 |

注意：**不是**理论值 4.0。实测干净 1080 素材只有 1.1~2.7，干净 406 素材 3.0~4.0，与分辨率强耦合。

## 1 镜头价值

基线 44 分起加，不是 100 分起扣——否则无缺陷镜头全满分，失去区分度。

| 项 | 分值 | 判定 |
|---|---|---|
| 清晰 | 0-22 | 人像看 `hair_detail`：<15 坏 / <40 软 / <62 良 / <340 优 / >340 判锐化过度（×0.82）<br>环境看 `sharpness`：<14 / <32 / <55 / <260 |
| 分辨率硬伤 | -10 或 -18 | 源宽 <1080 扣 10；<720 扣 18 |
| 主体 | 0-16 | `min(1, sr/0.30)`；有人脸再乘 `sqrt(min(1, face/0.10))`，人脸小乘 0.55 |
| 质感 | 0-12 | 高光溢出 >12% 扣 0.12；死黑 >8% 扣分 |
| 构图 | 0-6 | 三分线/中心取近；头顶留白 5-20% |
| 缺陷 | 扣分 | 甩镜 -30 / 抖动 >3 -17 / 轻微晃 >1.8 -7 / 死黑 -14 / 高光爆 -9 / 字幕压主体 -10 / UI 遮挡 -6 |

## 2 角色分类

`AFTER / BEFORE / PROCESS / DETAIL / CTA`，softmax(e × 3.2)。

组内百分位（中点法 `(a<v).mean() + 0.5*(a==v).mean()`）与绝对归一各占 50%。

**硬规则**（覆盖软加权）：

| 条件 | 判 |
|---|---|
| 无完整脸 + 大片肤色 | DETAIL |
| 无脸 + 无色 | CTA |
| 稳定露脸 + 发丝好 | AFTER |
| 稳定露脸 + 发丝差 | BEFORE |
| 背影大面积纹理 + 缓慢移动 | AFTER（成品展示，不加这条永远判废片） |
| 深色主体 + 平坦度高 + 面积小 | object → DETAIL |

**介质判别**：头发处处有纹理，包装是大片平坦色块。

| 素材 | 平坦块占比 | 主体面积 |
|---|---|---|
| 卷发背影 | 0.34-0.44 | 39.8% |
| 深色产品瓶 | 0.71 | 12.5% |

`flat_ratio > 0.60` 或 `area < 0.18` → object。

## 5 叙事

缺环扣分：HOOK -20 / PROCESS -22 / AFTER -24 / DETAIL -16 / BEFORE -14。
顺序：开头非钩子 -12；BEFORE 在 PROCESS 后 -8；AFTER 在 PROCESS 前 -10。
过程镜头 <2 个 -10，>5 个 -6。

## 8 技术质检（qc）

| 项 | 阈值 |
|---|---|
| 锐度（归一化） | <25 糊 -25 / <40 偏软 -12 / <62 略软 -6 |
| 抖动 | >3 明显 -15 / >1.8 轻微 -7 / `None` 报未测（不扣分但别当真） |
| 音频 | 峰值 >-1.0 dBTP 削波 / 响度不在 -16~-11 LUFS |

抖动只测**相机**：取四角 + 上下边中 6 个背景块做相位相关，块间位移标准差 >2.5px 整帧丢弃。整帧相关会把"模特甩头发"测成"摄影师手抖"（踩过：静止素材被误判 54.76）。
