# dp_beats.py —— 卡点剪辑切镜点求解器（可复用）

用途：给定一段配乐，自动求出「落在音乐重音上的镜头切点」，用于抖音/短视频 beat-sync 剪辑。

## 核心算法
1. 低频(35-200Hz)频谱通量 -> 瞬态强度包络
2. 局部峰值 -> 候选切点
3. 动态规划(DP)求最优切分序列
   - 约束：镜头时长 ∈ [min_d, max_d]
   - 代价：-重音强度 + 0.35 × |时长 - 理想时长|
4. 输出边界数组，直接喂给剪辑脚本

## 用法
```
python3 dp_beats.py music.mp3 --start 44.63 --total 20.5 --shots 14 --out bounds.json
```

## 参数
| 参数 | 说明 | 默认 |
|---|---|---|
| --start | 音乐起点（秒） | 自动找第一个强 kick |
| --total | 成片总长（秒） | 音乐全长 |
| --shots | 目标镜头数 | 14 |
| --min-d | 单镜最短时长（秒） | 0.72 |
| --max-d | 单镜最长时长（秒） | 1.85 |
| --prefer | 理想单镜时长（秒） | 1.25 |
